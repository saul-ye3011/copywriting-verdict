# Copywriting Verdict

## Core Position

Use the five-dimensional framework as the fixed judging engine.

Do not replace it with generic marketing advice. Do not soften its force into polite copy suggestions. Do not write clever lines before identifying the battlefield.

The skill has two primary jobs.

1. Write commercial copy
2. Judge and improve commercial copy

Both jobs pass through the same core.

```text
commercial context -> battlefield -> main attack angle -> line experiments -> meltdown elimination -> final delivery
```

## Non-Negotiable Principles

Start with the enemy.

A strong line must know what it is defeating, replacing, exposing, or reframing.

Prefer concrete nouns and verbs.

If the line depends on abstract praise, it is weak.

Write to a person, not about an asset.

For visual-led copy, identify what the viewer can already see and make the text add a useful shift in attention, interpretation, relevance, or action. A factual recap of the image or video is not copy.

Pick one dominant attack angle.

Do not average all five dimensions. A sharp line usually wins through one primary force, then uses the other dimensions to support it.

Kill weak lines.

Do not present many similar options. Generate, test, eliminate, then keep the strongest.

## Operating Flow

### Step 1 Diagnose The Situation

Build a compact map before writing or judging.

- Product or offer
- Target user
- Commercial scene
- Desired action
- Competitor or default solution
- User pain
- Hidden desire
- Purchase hesitation
- Available proof
- Tone boundary

If missing context changes the battlefield, ask up to three concise questions.

If the task can proceed with assumptions, state the assumptions briefly and continue.

### Step 2 Choose The Main Attack

Select one primary attack angle.

- Exclusionary verdict
- Reference frame shift
- Identity altar
- Sensory nail
- Desire permission
- Indirect praise
- Idiom hack
- Acoustic hook
- Meta-loop
- Hook-proof interlock

The chosen angle controls the writing. The other dimensions only support it.

### Step 3 Write Or Judge

For writing tasks, use the writing engine.

Generate at least three strategic directions. Each direction must use a different attack angle. Keep only the strongest lines after meltdown checks.

For critique tasks, use the critique rubric.

Judge first. Explain only the decisive cause. Rewrite only after the diagnosis is clear.

### Step 4 Apply Meltdown Checks

Before final delivery, test every line.

- Zombie words
- We or Our self-obsession
- Translation collapse
- Competitor replacement pass
- Abstract adjective stacking
- Claim without proof
- Cleverness without business force
- Smooth language without memory hook
- Emotional claim without scene
- No clear addressee or audience state
- Visual recap with no textual contribution
- Report language that describes the content container instead of speaking to the viewer

If a line fails, kill or rewrite it.

## Output Format

For writing tasks, default to this format.

1. Context judgment
2. Main attack angle
3. Candidate copy
4. Eliminated lines and reasons
5. Final recommendation
6. Hook-proof-action suggestion when useful

For critique tasks, default to this format.

1. Verdict
2. Core defect or core strength
3. Five-dimensional scan
4. Meltdown items
5. Rewrite direction

Keep the answer concise unless the user asks for deep analysis.
