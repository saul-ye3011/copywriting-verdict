# Context Diagnosis

Before writing, identify the real commercial battlefield.

## Minimum Context

- What is being sold
- Who buys it
- Where the copy appears
- What action should happen
- What competitors usually say
- What default solution can be attacked
- What proof exists
- What tone is allowed

## Audience State

Before writing, answer four questions in plain language.

- Who is encountering this line right now?
- What can that person already see or understand without the copy?
- What useful meaning, tension, consequence, or next thought is still missing?
- What would one real person naturally say to help that viewer notice it?

Object sense does not require using `you`. It requires a specific listener, a specific moment, and awareness of the listener's current attention. If the imagined reader is an auditor, content manager, or search engine instead of the actual audience, reset the diagnosis.

For image and video posts, separate visual evidence from text contribution.

```text
visible fact -> design or scene mechanism -> why it matters to this viewer -> what the line should add
```

Keep visual inventory for analysis and alt text. Do not automatically promote it into public-facing copy.

## Hidden Layer

Look for the buyer's unstated motive.

- Fear
- Greed
- Laziness
- Status
- Belonging
- Control
- Freedom
- Self-reward
- Moral justification

Good copy often gives the user permission to want what they already want.

## Diagnosis Questions

Use these questions internally before writing.

1. What existing belief or default industry solution should this copy defeat?
2. What does the buyer want but may feel awkward saying directly?
3. What concrete proof, scene, object, sound, or number can carry the message?
4. What should the buyer feel allowed to do after reading the line?
5. What would make the competitor unable to reuse this line honestly?
6. If the visual disappeared, would the line still make sense? If yes, it may be generic. If the line disappeared, would the viewer lose any useful interpretation or desire? If no, the line is redundant.

## If Context Is Thin

Ask no more than three questions when missing context changes the battlefield.

If assumptions are enough, write under assumptions and mark them briefly.
