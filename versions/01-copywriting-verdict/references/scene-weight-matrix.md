# Scene Weight Matrix

Use the same five dimensions with different weights by scene.

## Slogan

Highest weight:

- Strategic anchoring
- Language memory
- Translation meltdown
- Competitor replacement test

Lower weight:

- Detailed proof

## Packaging Copy

Highest weight:

- Cognitive physics
- Sensory nail
- Visual rhetoric
- Acoustic hook

Support weight:

- Desire button
- Scene credibility

## Website Hero

Highest weight:

- Strategic anchoring
- Hook-proof interlock
- Concrete proof
- User action

Support weight:

- Identity altar
- Idiom hack

## Product Selling Points

Highest weight:

- Scene logic
- Concrete nouns and verbs
- Proof
- Purchase hesitation

Support weight:

- Sound and rhythm

## Campaign Line

Highest weight:

- Identity altar
- Reference frame shift
- Value stance
- Idiom hack

Support weight:

- Product proof

## Brand Declaration

Highest weight:

- Value altar
- Strategic exclusion
- Reference frame shift
- Repeatability

Support weight:

- Detailed feature claims

## Visual Social Caption

Highest weight:

- Object sense and audience state
- Text contribution beyond visible facts
- Concrete perceptual or practical change
- Spoken naturalness
- Visual-copy interlock

Support weight:

- Search or category language
- Brand voice
- Detailed inventory already visible in the asset
